# Kado Digital — GitHub / Vercel upload checklist

1. Under the GitHub organization `kado-digital`, create a **private** repository named `kado-digital-website`. Leave "Add README" and other initialization options unchecked.
2. Extract this ZIP. Upload its **contents** to the repository root (not the ZIP file itself). The root must contain `index.html`, `about.html`, `css/`, `js/`, and `assets/`.
3. Verify on GitHub that `index.html` is in the root, and that `assets/kado-cat-logo.png` is present.
4. Vercel team `kado-digital-llc` is on Hobby, which is restricted to non-commercial use. This business services site requires an eligible commercial plan (e.g. Vercel Pro) before deployment. Do not upgrade without consent.
5. Once the repository is created and plan is eligible, connect `kado-digital/kado-digital-website` in Vercel: Framework "Other", root `.`, no build command, no output directory override. Deployment from Git can then update automatically when pushed to `main`.
6. Verify Home, About, Projects, Professional Websites, Resume, Contact, mobile navigation, cat logo, and contact mailto behavior.

Site is an interim design review, not an approved public launch. Check resume wording, contact email, real product screenshots, and social metadata before promotion.
