Algorithm Lab

Interactive scientific-computing demonstrations for optimization benchmarks, optimal transport, and ChiMerge discretization.

Independent / personalPublic sourcePersonal · Open source
Discuss a similar projectView Algorithm Lab on GitHub (opens in a new tab)

01 / THE IDEA

What it is

A Django-based portfolio of numerical computing experiments combining optimization landscapes, optimal transport demonstrations and ChiMerge discretization.

02 / THE BUILD

How it works

The application unifies three earlier histories, exposes visual modules and provides reproducible local development with Docker and automated tests.

  • Optimization benchmark landscapes for Ackley, Rastrigin, Griewank and Quadric
  • Transport plans, distribution interpolation and synthetic adaptation examples
  • ChiMerge interval boundaries on an abalone data set

Tools and technologies

  • Python
  • Django
  • NumPy
  • SciPy
  • Docker
