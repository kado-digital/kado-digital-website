01 / THE IDEA

What it is

Our own website is the studio’s public proof of craft: a minimalist geometric cat identity, cinematic scroll treatment, accessible navigation and a working website-design demonstrator.

02 / THE BUILD

How it works

The experience is deliberately dependency-light. It is built with semantic HTML, responsive CSS and small vanilla-JavaScript modules, then deployed automatically from GitHub to Cloudflare Pages.

  • Static HTML, CSS and JavaScript hosted on Cloudflare Pages
  • Responsive scroll scenes with reduced-motion fallbacks
  • A live website customizer demonstrating design directions
