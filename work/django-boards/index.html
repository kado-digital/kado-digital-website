01 / THE IDEA

What it is

A discussion-board application updated around production-minded Django conventions and a clear separation of settings and web routes.

02 / THE BUILD

How it works

Django ORM, admin and tests are paired with Gunicorn, WhiteNoise, environment-backed security and Docker workflows.

  • Boards, topics and admin functionality using the Django ORM
  • Runtime security settings, health endpoint and deployment checks
  • Docker Compose and GitHub Actions automation
