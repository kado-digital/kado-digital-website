MemeLife

A mobile merge game built in Godot, Kado Digital’s first original game.

Kado Digital LLCIn development2026

01 / THE IDEA

What it is

A playful mobile merging game built around growing up with internet culture. The experience explores item chains, character evolution and a progression system designed for quick sessions.

02 / THE BUILD

How it works

Godot 4.x is the target engine. The design includes an expandable merge board, producers, level rewards, an evolving cast and opt-in rewarded ads. A standalone technology-content lab exists, but it is not the complete game.

  • Tap producers to create mergeable items, then combine chains to progress
  • Level-based unlocks and a character timeline spanning early internet culture to modern social apps
  • Godot 4.x content experiments; commercial game source and launch still being finalized

Tools and technologies

  • Godot 4.x
  • GDScript
  • Game design
  • Mobile UX

03 / STATUS

Where it stands

Prototype stage. The full Godot game source is not currently available in the public portfolio, and no app-store release is claimed.
