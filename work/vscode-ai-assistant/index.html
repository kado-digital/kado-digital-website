01 / THE IDEA

What it is

A personal VS Code extension exploring what happens when one coding task flows through planning, implementation and an independent review.

02 / THE BUILD

How it works

Provider integrations aim for official tools and authenticated interfaces. A Git worktree is used for implementation so unfinished edits do not silently contaminate the main working copy.

  • Plan → implement → independently review in a controlled Git worktree
  • Fallback behavior for some quota/auth/transient failures with safety stops after partial edits
  • SecretStorage for provider keys; manual verification remains essential

Tools and technologies

  • JavaScript
  • VS Code API
  • Git worktrees
  • Multi-agent workflows
