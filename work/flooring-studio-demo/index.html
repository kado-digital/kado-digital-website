01 / THE IDEA

What it is

A React website concept for a premium flooring and interior-design brand, created as a sample of multi-page presentation and navigation patterns.

02 / THE BUILD

How it works

React Router and Ant Design support service pages, materials, project listings and contact/consultation interactions. The forms use mailto handoff rather than a backend.

  • Responsive React components and themed presentation
