01 / THE IDEA

What it is

A scroll-driven promotional concept tracing technology and internet culture across a lifetime, using parallax and layered illustrated scenes.

02 / THE BUILD

How it works

A static HTML, CSS and JavaScript site layers backgrounds, characters and foregrounds. Motion is tied to native scroll, with mobile and reduced-motion considerations.

  • Story-driven sequences, from personal computers and messenger apps to the smartphone era
  • Layered WebP artwork and scroll-controlled transitions
  • Still a project website concept, not proof that the mobile game has launched
